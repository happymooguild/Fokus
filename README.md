# Phocus

A Chrome extension that hides YouTube's distractions — and lets you put every
one of them back with a click.

Phocus is 23 independent switches. Turn off the homepage feed. Keep Shorts but
lose the comments. Strip the sidebar on a Tuesday and bring it back on Friday.
Nothing is permanent, nothing needs a reload, and nothing is hidden that you
didn't ask to hide.

## What you can hide

**Feed & navigation** — homepage feed · Shorts · Explore & Trending ·
More from YouTube · Subscriptions

**Watch page** — video sidebar (recommended videos · live chat · playlist
panel) · video info (buttons bar · channel row · description) · comments ·
Mix & radio playlists · merch, tickets & offers

**Player** — end screen videowall · end screen cards · autoplay · annotations

**Header & search** — top header (notification bell) · irrelevant search
results

Fresh installs start with the homepage feed and Shorts hidden. Everything else
is off until you say otherwise.

## Install

Phocus isn't on the Chrome Web Store yet. To run it from source:

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** and pick this folder

After editing any file, hit the reload icon on the Phocus card, then reload
your YouTube tabs.

## How it works

The whole extension is one idea: `src/content/phocus.css` is injected on every
YouTube page and every rule is gated behind an attribute selector —

```css
html[data-phocus~="comments"] ytd-comments#comments { display: none !important; }
```

`src/content/content.js` keeps `<html data-phocus="...">` in sync with
`chrome.storage.sync`. Flipping a switch rewrites one attribute, the browser
recalculates style, and the page updates. That is why toggling is instant, why
it reaches every open tab at once, and why turning something back on genuinely
restores it — nothing was ever removed from the DOM.

Three things can't be done in CSS, so the content script handles them:

- **Sidebar sections.** "Explore" and "More from YouTube" have no stable id and
  their headings are translated, so they're identified by where their links
  point, and only tagged when a clear majority of the section's entries match.
- **Redirects.** With Shorts hidden, `/shorts/<id>` becomes `/watch?v=<id>` so
  the video still plays, just in the normal player. With Subscriptions hidden,
  `/feed/subscriptions` goes to the homepage.
- **Autoplay and annotations**, which live behind the player's JS API.
  `src/content/player-bridge.js` runs in the page world to reach it. It only
  ever suppresses, and only ever undoes a suppression it performed — if you had
  autoplay off already, Phocus will never switch it on.

## Layout

```
manifest.json
icons/                     generated by hand, see git history
src/
  features.js              every toggle, defined once, shared by popup + content
  content/
    phocus.css             all the hiding rules
    content.js             storage sync, sidebar tagging, redirects
    player-bridge.js       page-world access to the player API
  popup/
    popup.html/.css/.js    the toggle UI
```

Adding a toggle means adding an entry to `src/features.js` and a rule to
`src/content/phocus.css`. The popup builds itself from the former.

## Permissions

`storage` to remember your switches, and host access to `youtube.com` to apply
them. No network requests, no analytics, no accounts. Settings ride
`chrome.storage.sync`, so they follow your Chrome profile.
